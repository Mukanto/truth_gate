## 3. Brief
- Claim: Gene-expression profiles allow the two classes to be told apart in new samples: the classification error rate is at most 0.40.
- Data keys:
   - `expression` float, (samples, genes): expression level of each gene in each sample
   - `class_b` bool, (samples,): True for a sample of class B, False for a sample of class A
- Sizes: samples 40, genes 2000.

## 4. Mapping
Error as documented in the private note: Nearest shrunken centroids is fitted for each threshold in a fixed grid of 20 values in [0.01, 1]; the 10-fold CV error is computed for every threshold on all 40 samples; the minimum CV error over thresholds (ties: larger threshold) is the statistic. Claim holds when that error <= 0.40.

Correction as documented: Nested cross-validation: outer leave-one-out over the 40 samples; in each outer iteration the threshold is chosen by 10-fold CV on the remaining 39 samples, the classifier is refit with it on those 39, and the held-out sample is classified; the statistic is the outer error rate.

Model-family choice in the private note: Nearest shrunken centroids with a threshold grid (the source's first classifier; MATLAB implementation, Delta in 0.01-1, ties to the larger Delta).

Lines of `faulty_body.py` that carry the error (parameters are those of the private note, where the source gives none the brief author's choice; the source's own sizes and bias figures are in the private note's `sizes_note`):
   - faulty_body.py line 73, `err = _cv_errors_nsc(x, y, folds, 10, deltas)`: 10-fold CV error for each of the 20 thresholds, all 40 samples.
   - faulty_body.py line 74, `stat = err[_pick_delta(err)] / n`: the smallest of these errors (ties: larger threshold) is the statistic.
   - faulty_body.py line 71, `deltas = np.linspace(0.01, 1.0, 20)`: threshold grid: 20 values in [0.01, 1].

Lines of `fixed_body.py` that carry the correction:
   - fixed_body.py line 73, `for i in range(n):`: outer leave-one-out loop.
   - fixed_body.py line 78, `best = _pick_delta(_cv_errors_nsc(xi, yi, inner, 10, deltas))`: threshold chosen by 10-fold CV on the remaining 39 samples (ties: larger threshold).
   - fixed_body.py line 79, `errors += int(_nsc_errors(xi, yi, x[i:i + 1], y[i:i + 1], deltas[best:best + 1])[0])`: classifier refitted on the 39 with that threshold, held-out sample classified.
   - fixed_body.py line 80, `stat = errors / n`: outer error rate.

The remaining lines (helpers, guards, statistic and threshold line) are identical in the two files. `criterion` occupies
lines 56 to 81 of fixed_body.py.

Implementation choices the private note leaves open (identical in both files): Stratified inner folds. Nearest shrunken centroids as in Tibshirani et al.: d = (class mean - overall mean) / (m_k (s_j + s0)), m_k = sqrt(1/n_k - 1/n), s0 = median s_j, soft threshold, class-share priors, discriminant with the shrunken centroids. Threshold grid np.linspace(0.01, 1, 20).

**Estimand.** Faulty: the smallest of many CV errors, an estimate biased downwards by the choice of its own minimum. Fixed: expected error on new samples of the whole procedure including threshold choice.
