## 4. Mapping
Error as documented in the private note: Ridge regression of response on [standardised expression, standardised clinical covariates] (penalty fixed at lambda = number of columns) is fitted on all 80 patients; the Pearson correlation between its fitted values and the observed response, on the same 80 patients, is the statistic (resubstitution). Claim holds when r >= 0.30.

Correction as documented: Same model; predictions for each patient come from 10-fold cross-validation (patients in the held-out fold are not used in fitting or standardising); r is the Pearson correlation between these held-out predictions and the observed response.

Model-family choice in the private note: Ridge regression with a fixed penalty on the concatenated standardised blocks. Chosen by me: the source names no model; fixed penalty avoids tuning (stays L1.1).

   - faulty_body.py line 53, `lam = float(x.shape[1])`: ridge penalty = number of columns (brief author's choice).
