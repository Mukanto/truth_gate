## 3. Brief
- Claim: Gene-expression profiles measured at diagnosis predict survival time in new patients: the out-of-sample R-squared for predicting survival_months from the expression profile is at least 0.10.
- Data keys:
   - `expression` float, (patients, genes): log2 expression level of each gene in each patient's tumour sample
   - `survival_months` float, (patients,): months from diagnosis to death, observed for every patient
- Sizes: patients 50, genes 2000.

## 4. Mapping
Error as documented in the private note: Ridge regression of survival_months on standardised expression (all 2000 genes, penalty fixed at lambda = number of genes, no tuning, no gene selection) is fitted on all 50 patients, and R-squared is computed on those same 50 patients (resubstitution). Claim holds when that R-squared >= 0.10.

Correction as documented: Same ridge model, but R-squared is out-of-sample: 5-fold cross-validation over patients, R-squared = 1 - SSE/SST from the pooled held-out predictions, with the test-fold patients never used in fitting or in standardising.

Model-family choice in the private note: Ridge regression with a fixed penalty on standardised expression. Chosen by me: the source names no model; a fixed penalty avoids any tuning or selection step so the only error is the missing test set (L1.1, not L1.3).

Lines of `faulty_body.py` that carry the error (parameters are those of the private note, where the source gives none the brief author's choice; the source's own sizes and bias figures are in the private note's `sizes_note`):
   - faulty_body.py line 48, `pred = _ridge_predict(x, y, x, lam)`: model fitted on all patients and applied to the same patients (resubstitution).
   - faulty_body.py line 47, `lam = float(x.shape[1])`: ridge penalty = number of genes (chosen by the brief author; no source value).

Lines of `fixed_body.py` that carry the correction:
   - fixed_body.py line 48, `folds = _random_folds(rng, n, 5)`: 5-fold partition of the patients.
   - fixed_body.py line 52, `pred[te] = _ridge_predict(x[~te], y[~te], x[te], lam)`: each held-out fold predicted by a model fitted (and standardised) on the other folds only.

The remaining lines (helpers, guards, statistic and threshold line) are identical in the two files. `criterion` occupies
lines 33 to 53 of fixed_body.py.

Implementation choices the private note leaves open (identical in both files): Ridge in dual form on columns standardised with the training part (a constant column is left at zero). Folds are uniformly random, 5 folds. SST is about the mean of all patients' y.

**Estimand.** Faulty: in-sample fit of the model to the patients that built it. Fixed: expected R-squared of the model on new patients from the same population.
