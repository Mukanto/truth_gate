## 3. Brief
- Claim: Gene-expression profiles allow tumour tissue to be distinguished from normal tissue in new samples: the classification error rate is at most 0.20.
- Data keys:
   - `expression` float, (tissues, genes): log expression level of each gene in each tissue sample
   - `tumour` bool, (tissues,): True for a tumour tissue sample, False for a normal tissue sample
- Sizes: tissues 62, genes 2000.

## 4. Mapping
Error as documented in the private note: All 62 tissues are used to rank genes by absolute two-sample t-statistic; the top 3 genes are kept; 10-fold cross-validation of Fisher's linear discriminant on those 3 genes is run on all tissues and its error rate is the statistic. Claim holds when error <= 0.20.

Correction as documented: Within each of the 10 folds, genes are ranked and the top 3 chosen using the training tissues only; the discriminant is fitted on those genes and applied to the test fold; the error rate is pooled over folds.

Model-family choice in the private note: t-statistic gene ranking, top 3 genes, Fisher's linear discriminant: the source's own method (Fisher LDA with a 3-gene subset on colon and leukaemia data), simplified to a t ranking so that it is cheap and unambiguous.

Lines of `faulty_body.py` that carry the error (parameters are those of the private note, where the source gives none the brief author's choice; the source's own sizes and bias figures are in the private note's `sizes_note`):
   - faulty_body.py line 57, `sel = _top_genes(x, y, 3)`: top 3 genes by |t| chosen once on all tissues, before the cross-validation.
   - faulty_body.py line 63, `pred[te] = _lda_predict(xs[~te], y[~te], xs[te])`: the cross-validation then runs on those pre-selected genes.

Lines of `fixed_body.py` that carry the correction:
   - fixed_body.py line 61, `sel = _top_genes(x[~te], y[~te], 3)`: top 3 genes chosen inside each fold, on the training tissues only.
   - fixed_body.py line 62, `pred[te] = _lda_predict(x[~te][:, sel], y[~te], x[te][:, sel])`: discriminant fitted and applied on those genes.

The remaining lines (helpers, guards, statistic and threshold line) are identical in the two files. `criterion` occupies
lines 42 to 63 of fixed_body.py.

Implementation choices the private note leaves open (identical in both files): Stratified folds. t-statistic with pooled variance; top 3 by absolute value (stable ties). Fisher discriminant with the pooled within-class covariance (pseudo-inverse) and the midpoint threshold (equal priors).

**Estimand.** Faulty: error of a rule whose genes were chosen using the test tissues' labels. Fixed: expected error of the whole procedure (gene choice plus discriminant) on new tissues.
